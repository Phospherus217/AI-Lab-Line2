# Task01 现代AI编程环境配置
## 环境清单（AI研发三件套）
1. AI IDE：Trae（AI原生代码编辑器）
2. 终端AI Agent：Aider v0.86.2
3. 大模型API：SiliconFlow硅基流动（免费额度）

## 配置步骤
1. 安装Trae，打开并测试AI代码补全功能，截图保存界面。
2. 安装Python，使用pip安装Aider，配置API环境变量。
3. 启动Aider，对接SiliconFlow大模型，在终端交互，自动生成test.py代码文件。
