# Task 01 环境配置与 DSH 协同实战说明

## 1. 任务目标
按照实验室通识任务文档要求，安装并配置开源终端 Coding Agent 工具（DSH / DeepSeek Harness），配置相关环境，并完成一次交互式辅助脚本编写。

## 2. 环境配置
*   **使用的终端 AI 工具**：DSH (DeepSeek Harness)
*   **编程语言环境**：Python 3.14.4 (64-bit)
*   **配置过程**：
    1. 在 DSH 默认工作区中，授权 `workspace-write` 权限。
    2. 借助 DSH 的引导，下载并运行了官方 Python 安装程序。
    3. 在安装过程中按照提示勾选了 `Add Python to PATH`（添加环境变量），并根据系统安全提示授予了临时的 `full access` 权限以完成系统目录写入。
    4. 安装完成后，DSH 自动调用系统级 Python 进行了环境验证。

## 3. 实战交互与成果
*   **交互过程**：在 DSH 聊天终端中，输入需求让其辅助编写了一个具备中文注释和异常处理的 Python 简单计算器脚本（calculator.py）。
*   **实战成果**：DSH 成功生成了 107 行的 Python 代码，包含 13 项自定义测试用例。
*   **运行验证**：DSH 自动在底层终端中运行了该脚本，所有 13 项测试全部通过，环境配置与 AI 协同编码功能验证无误。
